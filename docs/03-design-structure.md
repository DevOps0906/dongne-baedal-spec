# 03. 디자인 구조

> 고객 · 라이더 · 계약업체 · 관리자 4역할의 화면 구조와 디자인 규칙입니다.
> 시안은 `design/canvas.html`의 「디자인」 탭에서 볼 수 있습니다.
> 배민은 구조와 흐름만 참고했고, 색·폰트·문구는 자체 기준입니다.

## 1. 디자인 원칙

| 원칙 | 의미 | 적용 |
|---|---|---|
| 한눈에 결정 | 가게 카드 한 장으로 고를 수 있게 | 평점·배달시간·배달팁·최소주문을 한 줄 메타로 |
| 지금 어디쯤 | 주문 후 불안을 줄인다 | 단계 타임라인 + 라이더 지도 + 도착 예정 시간을 한 화면에 |
| 사장님은 바쁘다 | 대시보드는 손이 덜 가게 | 신규 주문은 큰 카드·소리·한 번 탭 접수, 품절은 토글 하나 |
| 숫자는 정직하게 | 정산은 계산식이 보이게 | 정산 예정액 옆에 공제 항목을 펼쳐 보여줌 |

## 2. 브랜드 기본값

| 항목 | 값 |
|---|---|
| 브랜드 컬러 | 코랄 `#FF5A36` (brand-500), 눌림 `#E84521` |
| 보조 | 뉴트럴 그레이 10단계, 상태색 4종 (success·warning·danger·info) |
| 폰트 | Pretendard (본문·제목 공통), 숫자는 `tabular-nums` |
| 모서리 | 카드 16, 버튼·입력 12, 바텀시트 상단 20, 칩 999 |
| 밀도 | 고객 앱 Comfortable, 업주·관리자 대시보드 Compact |
| 아이콘 | web Lucide, Flutter Material Symbols Rounded |

## 3. 반응형 3구간

| 구간 | 범위(px) | 고객 화면 | 업주·관리자 대시보드 | 라이더 |
|---|---|---|---|---|
| 모바일 | ~767 | 1열 카드, 하단 5탭 | 하단 탭 4개(주문·상품·매출·더보기), 주문은 카드 리스트 | 기준 화면 |
| 태블릿 | 768~1199 | 2열 그리드, 상단 검색 확장, 하단 탭 유지 | 좌측 아이콘 레일(72px) + 주문 칸반 2열 | 가로 모드 지도 |
| 데스크탑 | 1200~ | 최대 폭 1120 중앙, 3열, 좌측 카테고리 사이드바 | 좌측 사이드바(240px) + 상단 바 + 4열 KPI + 칸반 4열 | — |

### 구간별 글자 크기 (px)

| 역할 | 모바일 | 태블릿 | 데스크탑 | 쓰임 |
|---|---|---|---|---|
| display | 28 | 32 | 40 | 홈 인사말, 대시보드 큰 숫자 |
| title | 20 | 22 | 24 | 화면 제목, 가게 이름 |
| subtitle | 17 | 18 | 20 | 섹션 제목, 메뉴 이름 |
| body | 15 | 16 | 16 | 본문, 리스트 |
| caption | 12 | 13 | 14 | 메타 정보, 보조 설명 |

대시보드는 같은 단계를 쓰되 표 본문만 14px(데스크탑)로 줄입니다.

### 핵심 컴포넌트

- **가게 카드:** 썸네일 16:9(대표 메뉴 3장 콜라주 옵션) → 가게명 → `★4.8 (1,203) · 25~35분 · 배달팁 0~3,000원` → 쿠폰 배지
- **배달정보 바:** 최소주문 / 배달팁 / 예상시간 3칸, 탭하면 배달팁 구간표 시트
- **옵션 그룹:** 제목 + 「필수」·「최대 2개」 배지, 라디오(단일)/체크박스(다중), 추가금 우측 정렬
- **최소주문 진행바:** 미달 시 「n원 더 담으면 주문할 수 있어요」
- **주문 타임라인:** 주문접수 → 조리중 → 픽업 → 배달중 → 완료, 현재 단계만 브랜드색 강조 + 아이콘 + 텍스트

## 8. 지도 UI 규칙

| 마커 | 모양 | 색 |
|---|---|---|
| 가게 | 둥근 사각 + 가게 아이콘 | neutral-900 |
| 라이더 | 원 + 진행 방향 화살표, 이동 시 부드럽게 보간 | brand-500 |
| 배달지(집) | 핀 + 집 아이콘 | info |

- 지도는 화면 높이의 55%(모바일), 남은 영역은 드래그 가능한 바텀시트
- 위치 신호가 30초 이상 끊기면 마커를 반투명 처리하고 「위치를 확인하고 있어요」 표시
- 지도 SDK: 1차 네이버 지도(국내 주소 정확도), 대안 카카오맵. spec에서는 SDK에 의존하지 않는 마커 규칙만 정의

## 10. 접근성

- 본문 명도 대비 4.5:1 이상 (브랜드색 위 흰 글자는 18px 이상 굵게에만 사용)
- 터치 영역 최소 44×44, 라이더 주요 버튼 56 이상
- 상태는 색 + 아이콘 + 텍스트로 함께 표시
- 시스템 글자 크기 확대 지원, 지도 정보는 텍스트(도착 예정·거리)로도 제공
