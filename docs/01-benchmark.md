# 01. 배달의민족 벤치마킹 분석

> 목적: 배민의 **기획 구조·디자인 구조**를 분석해 동네배달의 설계 근거로 쓴다.
> 원칙: 구조와 흐름만 참고한다. 배민의 이름·로고·민트 코드·WORK체는 쓰지 않는다.
> 조사 시점: 2026-10-24 (공개 기사·앱스토어 설명·디자인 매체 기준)

## 1. 홈 화면 구조

- 홈이 카드형 구성에서 **서비스별 탭 구조**로 바뀌었다. 상단 탭에 배민배달·가게배달·장보기·쇼핑·선물하기가 나란히 노출된다.
- 배민배달·가게배달 탭을 누르면 같은 크기의 서비스 화면이 나오고, 그 안에서 치킨·족발 등 음식 카테고리를 고른다.
- 노출은 개인 맞춤형이다.
- 앱스토어 설명 기준 부가 기능: 픽업, 선물하기, 전국특가, 배민클럽(멤버십), 실시간 라이더 위치 확인.

**동네배달 적용**
| 배민 | 동네배달 MVP | 비고 |
|---|---|---|
| 배민배달(단건) | 동네배달 | 1차 구현 |
| 가게배달 | 가게배달(업주 직배송) | 1차 구현, 주문 흐름은 동일 |
| 픽업 | 포장 | 1차 구현 |
| 장보기·쇼핑(B마트) | 장보기 | 2차 (스키마만 확장 여지) |
| 선물하기 | - | 3차 |
| 배민클럽 | 멤버십 | 3차 |

## 2. 주문 흐름

가게 탐색 → 가게 상세 → 메뉴 옵션 선택 → 장바구니 → 주문서(배달지·결제·쿠폰·요청사항) → 결제 → 주문 접수 → 조리 → 배달 → 완료 → 리뷰.
상세 다이어그램은 `docs/02-diagrams.md` 참고.

## 3. 사업 구조 (3면 플랫폼)

소비자·업주·라이더가 맞물리는 구조다. 수익원은 중개수수료(약 60%), 광고(약 15%), 배달비(약 15%), 커머스(약 10%)로 알려져 있다.

**동네배달 적용:** 3역할을 모두 데이터 모델에 둔다.
- 소비자 앱 (이번 범위의 중심)
- 업주 관리자 (주문 접수·메뉴 관리, `web` 레포의 `/owner`)
- 라이더 (MVP에서는 상태 변경만 하는 단순 화면)

수익 모델은 MVP에서 **중개수수료율 필드(`stores.commission_rate`)** 만 두고, 광고·멤버십은 후순위로 둔다.

## 4. 디자인 구조

- 2025년 리브랜딩으로 밝은 민트색과 전용 서체(WORK체)를 도입했다. 컨셉은 "볼드 & 심플"이다.
- 버튼·배경 등 기능별로 명도·채도를 체계화한 컬러 시스템을 만들었다.
- 둥근 모서리(12~18px), 둥근 검색창, 모듈형 서비스 카드, 넓은 흰 배경, 짧은 행동 카피가 특징이다.
- UX 라이팅은 친근하고 위트 있는 말투다.

**동네배달 적용**
- 색: 자체 브랜드 컬러(코랄 계열)와 기능별 단계 토큰. 민트는 쓰지 않는다.
- 폰트: Pretendard (오픈 라이선스). WORK체·한나체 계열은 쓰지 않는다.
- 모서리 12~18px, Comfortable 밀도, 모듈형 카드는 그대로 구조만 차용한다.
- 카피 톤은 짧고 친근하게, 문구는 직접 작성한다.

## 4-1. 추가 범위 (요청 반영)

| 영역 | 배민 기준 | 동네배달 반영 |
|---|---|---|
| 메뉴 구조 | 하단 탭 + 홈 서비스 탭 + 카테고리 + 가게 상세 탭(메뉴·정보·리뷰) | 고객 IA 전체 (`02-diagrams.md` 2장) |
| 배달 추적 | 앱에서 라이더 실시간 위치 확인 | 라이더 위치 전송·지도 추적 (8·9장) |
| 계약업체 | 사장님 전용 채널에서 메뉴·옵션·영업 관리, 주문 접수 | `/partner` 대시보드, 입점·상품 등록 흐름 (4·10장) |
| 결제·정산 | 앱 결제, 업주 정산(수수료·배달비 공제) | 결제·환불 흐름, 정산 원장·대시보드 (11·12장) |
| 운영 | 본사 관제 | `/admin` 대시보드 (5장) |

## 5. 위험·주의

| 항목 | 대응 |
|---|---|
| 상표·저작권 | 이름·로고·색 코드·폰트 미사용. 문구는 자체 작성 |
| 결제 | MVP는 결제 모의(`payments.provider = 'mock'`), 실결제는 PG 계약 후 |
| 위치·주소 | 주소 검색은 외부 API 연동 전까지 입력형 + 좌표 필드만 확보 |
| 개인정보 | 주소·연락처는 RLS로 본인만 조회 |
